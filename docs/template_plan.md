## 四、复现规范

- 全部用 Matplotlib / Seaborn / Plotly 生成，不使用 Excel 截图或 BI 软件；
- 分辨率 ≥150 dpi（建议 200 dpi）；
- 中文字体正常显示，坐标轴、单位、图例、标题完整；
- 统一命名 `fig01_描述.png` … `fig10_描述.png`；
- 每张图保留生成脚本，脚本可独立运行；
- 完成后生成 `docs/template_charts.md` 索引，记录原模板、脚本、输出、对照方式。
